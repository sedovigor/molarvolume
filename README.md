# molarvolume
Python functions to calculate:
1) van der Waals volume (in Å<sup>3</sup>) of any molecule from SMILES using atom contributions (VABC scheme), the dictionary contains all elements;
2) molar volume of ionic liquids at 298.15 K (in cm<sup>3</sup>/mol) using a correlation with van der Waals volumes of ions. Not suitable for molecular liquids.
